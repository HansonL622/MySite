# Zhenghan 的作品小屋

这是我设计并开发的互动个人主页。我把作品集做成了一座可以探索的小屋：推开入口的大门，沿着 3D 走廊前进，走近不同的房间，就能了解我的教育经历、实习经历、项目和联系方式。

页面支持键盘、鼠标滚轮和手机触控操作。走廊中的房门会随着距离变化而打开，点击房门可以查看对应内容。视觉上结合了彩色涂鸦字母、日漫风格的天空和空间场景，希望让浏览作品集的过程更有趣。

项目使用 JavaScript、Three.js 和 Vite 开发。

在线体验：[Zhenghan 的作品小屋](https://zhenghan-portfolio-site.vercel.app/)
