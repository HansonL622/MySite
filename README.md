# Zhenghan 的作品小屋 · 日漫风格重构初稿

独立实现的互动作品集原型。推门进入时，彩色涂鸦字母「ZHENG HAN」先出现，再从画面中线向两侧分开，露出可循环探索的 3D 走廊。屋内有连续透视的地板、侧墙、顶梁与作品门；方向键上下、W/S、滚轮、手机纵向滑动、点击走廊中央或前进按钮都可以移动，路段会循环出现。所有场景几何、界面、文案与天空背景均在本项目中重新制作。没有引入 ITom 项目的代码、纹理、插画或文案。

运行：Node.js 20 以上，执行 `npm install`、`npm run dev`。构建：`npm run build`。

屋内分为教育、实习、项目、Contact Me 四个区域，以走廊两侧的房门呈现。走近时门会自动半开，走远后复位，点击门可查看内容。教育、实习和联系方式暂用明确的待补充文案；项目区列出的名称只是示例方向，真实经历、成果、图片和链接可继续替换。天空背景为本次生成的原创图片素材。
